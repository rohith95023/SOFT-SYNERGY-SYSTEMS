# 🗺️ Website Content Map (Constants Guide)

This guide provides a detailed mapping of every section of the website to its corresponding file. If you want to change any text, please refer to the tables below.

---

## 🛑 Important: How to Edit
1. **Find the right file**: Locate the page and section in the tables below.
2. **Edit the Text**: Only change the text *inside* the single quotes (`'Like This'`).
3. **Don't touch the symbols**: Avoid deleting commas (`,`), colons (`:`), or brackets (`{` `}`).
4. **Save**: The website will update automatically once you save the file.
